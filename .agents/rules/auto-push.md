# Auto Git Push & Hostinger Deployment Rule

Whenever you finish a coding task or fix in this repository:
1. Verify the changes run/compile cleanly.
2. Stage modified files (`git add .` or specific files).
3. Commit with a descriptive message in Indonesian or English.
4. Push to GitHub (`git push origin main`).
5. Confirm to the user that changes have been committed and pushed to GitHub (which automatically triggers Hostinger auto-deployment).
